# Jaemulun UI Assets

재물운 마스터의 실제 웹 UI 배치를 위한 production PNG asset pack.

## 규칙
- production asset은 모두 512×512 RGBA PNG입니다.
- 모든 파일은 실제 alpha transparency를 갖습니다.
- HTML 텍스트/버튼을 가리는 방식으로 배치하지 않습니다.
- 모바일에서 권장 표시 크기는 대체로 36~160 CSS px입니다.
