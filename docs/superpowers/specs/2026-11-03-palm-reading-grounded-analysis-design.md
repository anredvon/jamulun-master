# 손금 출처 기반 풀이와 사진 판독 설계

## 목표

사진에서 손이 아닌 이미지와 판독에 부적합한 손 사진을 걸러내고, 공개 손금 자료를 바탕으로 출처와 편집 검토 상태를 관리하는 좌우 손별 전통 풀이를 제공한다.

## 현재 상태

- 손금 선 분석은 `static/js/palm-analysis.js`에서 전 픽셀의 명도 차이로 가로·세로 후보를 찾는다. 손 검출, 손바닥 면적, 손바닥 앞면 여부, 사진 완전성 검증이 없다.
- 결과는 세 선 가운데 2개 후보가 있으면 사용 가능으로 처리한다. 후보 하나만 있어도 내부 알고리즘은 `usable`을 반환한다.
- 해석은 `static/data/palm-combinations.json`과 `static/js/palm-copy.js`의 고정 문구 조합이며, 출처/페이지/해석 전통 메타데이터가 없다.
- `models.py`에는 퀴즈와 세션 모델만 있다. 현재 손 사진은 브라우저에서 처리하고 서버 업로드 엔드포인트가 없다.

## 접근 방식

1. **현재 픽셀 휴리스틱만 보강:** 의존성은 작지만 손이 아닌 이미지와 가림·잘림을 안정적으로 구별하기 어렵다.
2. **기기 내 손 랜드마크 + 손바닥 선 영상처리:** 손 위치·좌우·관절을 먼저 판별하고, 정렬된 손바닥 관심 영역에서 선 후보와 이미지 품질을 판별한다. 사진은 브라우저 안에 유지한다. 이 안을 선택한다.
3. **외부 이미지 분석 API:** 구현은 단순해질 수 있으나 손 사진 전송이 필요해 현재 개인정보 안내와 충돌하므로 제외한다.

## 사용자 흐름과 판독 기준

- 좌우 손 사진을 각각 받는다. 사용자가 사진별 좌우를 직접 지정해 거울 셀카의 손 방향 오인을 피하고, 주로 쓰는 손도 선택하도록 한다. 출처 자료가 뒷받침할 때만 주손/비주손 차이를 풀이에 반영한다.
- 사진 적합성은 손 검출, 손바닥 앞면 확인, 손목과 손가락 시작점까지의 프레임 포함, 손바닥 크기, 초점/노출, 선 판독 신뢰도를 단계별로 판정한다.
- 손 없음, 손등, 손이 잘림, 흐림/노출 부족, 주요 선 판독 실패를 구분해 재촬영 안내를 보여준다.
- 손이 충분히 보이지만 일부 선만 불명확한 경우 사진 자체를 무조건 거절하지 않는다. 확인할 수 없는 선은 “판독 어려움”으로 표시하며 다른 유형을 대신 끼워 넣지 않는다.
- MediaPipe Hand Landmarker는 손바닥 면/손등 면을 직접 분류하지 않는다. 주요 손바닥 주름이 보이지 않는 경우 “손바닥 선이 보이지 않음”으로 재촬영을 안내하되, 이를 손등 판정으로 단정하지 않는다.
- 판독 임계값은 임의의 픽셀 숫자로 확정하지 않고 대표적인 정상/부적합 사진군을 확보해 조정한다. 실제 손 사진에 대한 검증 전에는 정확도를 보장하지 않는다.

## 출처와 손금 지식 데이터

- 구현용 초기 코퍼스는 `Key to Palmistry` (1902), `Indian Palmistry` (1895), `Palmistry for All` (1916) 세 자료의 선 위치/상징 설명을 비교한다. 이 자료들은 전통 해석의 근거이지 과학적 타당성의 근거가 아니다. `Indian Palmistry`는 빅토리아 시대 영문 출판물이므로 인도 손금 전통 전체를 대표한다고 부르지 않는다.
- 원문을 대량 복제하지 않는다. 앱용 한국어 풀이는 편집해 작성하고 출처 책, 저자, 연도, 원문 페이지/항목, 권리 안내, 전통/학파, 검토 상태를 기록한다.
- 각 해석 항목은 선 종류와 관찰 특징 코드, 전통적 풀이, 일상 성찰 질문, 출처 식별자를 갖는다.
- 해석 전통 간 상충은 하나의 정답으로 합치지 않고 출처 관점을 표시한다. 주손 구분은 해당 출처에 근거가 있는 항목에만 연결한다.
- 기존 전체 조합 JSON을 그대로 DB에 옮기지 않고, 출처가 연결된 재사용 가능한 풀이 항목을 저장한 뒤 런타임에 관찰 특징에 맞춰 조합한다.

## DB와 개인정보

- `palm_sources`와 `palm_reading_rules` 전용 모델을 추가한다. 소스는 제목/저자/연도/URL/권리 및 지역 범위/확인일을 관리한다. 풀이 규칙은 선 종류/특징/전통적 해석/성찰 문구/출처 페이지/검토 상태/버전을 관리한다.
- 첫 데이터셋은 검토 가능한 버전 관리 파일로 정리한 뒤 seed/import 경로로 DB에 넣는다. 운영 DB에 직접 일괄 입력하지 않는다.
- 사용자 손 사진, 랜드마크, 원시 손금선은 서버에 저장하지 않는다. 이미지 특징은 기기 내에서만 처리한다. 사용자가 명시적으로 기록을 저장할 때 기존 손금 결과 요약만 저장한다.
- MediaPipe Tasks Vision Web 1.2.0 and its hand-landmarker model are self-hosted under their Apache-2.0 notices. Its model-card caveat is carried into product QA: the hand-landmarker model is experimental and not validated for every real-world mobile camera condition. Palm-vs-back classification remains a crease-visibility heuristic, not a model guarantee.

## 문구와 한계

- 결과를 전통 해석과 자기성찰 콘텐츠로 소개한다. 과학적 진단, 건강·수명·재물·미래 예측으로 표현하지 않는다.
- 사진에서 관찰한 특징과 전통 해석을 구분해 보여준다. 확인 불가한 특징은 단정하지 않는다.
- 손금 해석은 과학적으로 검증된 개인 진단이 아니다. 이미지 처리 성능 역시 별도 실제 사진 검증 전까지 확정적으로 홍보하지 않는다.

## 승인된 범위

- 출처 자료를 조사해 초기 검토 데이터셋을 작성한다.
- 좌우 손 캡처, 주손 입력, 사진 적합성 안내, 온디바이스 이미지 분석, 전용 DB 구조를 구현한다.
- 배포/운영 DB 변경은 포함하지 않는다.
